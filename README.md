# 纸世界 · Paper World

> 一个 2020 年提出、2023 年成文的构想：
> **软件的形态可以是临时的，只有数据与语义需要长期存在。**

这个仓库不是代码库，是一份**构想的档案与研究记录**。
它记录了一个直觉如何被提出，以及六年后，2026 年的前沿技术如何一条条追上它、并且留下了一个仍然空着的格子。

---

## 一句话

> AI 直接生成一件你此刻要用的东西——说不清是菜单还是 APP——
> 用完立即销毁，**但数据保持连续**。

听起来像科幻。但拆开看，它是三个可以被单独检验的命题。

## 三个可检验命题

| 命题 | 形式化表述 | 2026 年状态 |
|---|---|---|
| **P1 界面不是资产** | 界面 = f(状态, 意图)，随用随算，不必预先存在 | ✅ 已被工业界部分实现 |
| **P2 生命周期短于产品周期** | 生成物寿命 = 本次使用时长，而非软件版本周期 | ⚠️ 组件级已实现，界面级没有 |
| **P3 状态与界面彻底解耦** | 丢弃界面不损失任何信息 | ✅ 已有形式化保证 |

"叫菜单还是叫 APP"的困惑，根源是 P1 与 P2 同时成立时旧词汇失效：
**菜单**隐含"功能已存在"，**APP** 隐含"预装、常驻、有版本"，两者都默认软件是**持久物件**。
而这个构想描述的是**软件作为一次事件**。

---

## 六年后，前沿走到了哪里

2026 年，四家机构在四个不同层上做了同一个动作：**把"常驻"改成"按需"**。

| 谁 | 拆开的东西 | 手段 | 与本文的关系 |
|---|---|---|---|
| **DeepSeek Harness** | 组件的生命周期 | 可逆效应 + 反应式余效应 + 汇流性定理 | ★ **理论地基** |
| **DeepSeek Engram** | 记忆 / 推理 | 哈希查表 + 冷热分离 | 效率论证 |
| **OpenAI Apps SDK** | 界面 / APP | MCP + 内联 widget | 产品化样板（差一格） |
| **Anthropic Agent Skills** | 规则 / 常驻提示 | 按需加载 + schema + hook | 分层方法论 |

**最关键的一条**：DeepSeek Harness 配套论文
《A Programming Paradigm for Spatiotemporal Composability》
（arXiv 2608.25512）里的**汇流性定理**，恰好是这个构想里"数据保持不变"的严格版本：

> 不论系统经历怎样一串组件的激活与去激活，
> 它最终静止时的状态，等同于把同样的指令一次性执行、从未卸载所得到的状态。

**生成、使用、销毁，重复一万次，系统状态和"从来没生成过"完全一致。**

而 OpenAI 的 Apps SDK 已经把"界面在对话里当场渲染、按需出现"做成了产品，
但它生成的是**"该不该出现、出现哪一个"**，界面本身仍由开发者预制。

```
OpenAI：界面预制，选择生成     ← 已实现
本构想：界面本身生成           ← 仍然空白
```

这一格，就是这个项目存在的理由。

## 现在能做什么

`02-三层整理.md` 把全部构想切成四级，判据是**瓶颈类型**（材料 / 制度 / 范式）：

- **A 级 · 现在就能做** — 状态与界面解耦、MCP 能力层、可逆效应管生命周期、生成即带 cleanup
- **B 级 · 1–3 年** — 受 schema 约束的界面生成、可验证的逆、汇流性测试、行为评估
- **C 级 · 3–5 年** — 跨设备语义同步、可验证生成、多租户隔离
- **D 级 · 仍是幻想** — 电子纸、盖亚系统、无穷纸、**完全无预设的界面生成**

**D 级请从核心设计里划掉。** 划掉不影响任何 A 级工作——
这大概也解释了为什么这个构想放了六年没法动手：它被硬件叙事绑住了。

## 一条必要条件

> **生成的东西必须自带它的逆。**

DeepSeek Harness 的论文指出：副作用必须由**施加者当场提供一个显式的逆函数**，运行时不会帮你推导。
所以"生成界面"这个动作，必须在同一时刻生成它的 cleanup——否则造出来的就是
VSCode 那种"卸载必须重启整个宿主"的扩展。

这是整个方案**最容易死的地方**，也是第一个该验证的地方：

> 生成 / 销毁 100 次后，上下文哈希是否等于初始值？

这个数不过，后面全是空中楼阁；这个数过了，就拿到了一个目前还没有人拿出的证据。

## 一条修正

原文说"数据保持不变"。

建议改为：**数据不变，但痕迹留下。**

因为"数据不变"只保住了结果，没保住过程；而人回忆时，回忆的恰恰是过程。
界面的形状是那一瞬间的**解**，你做的动作才是**题**——存题不存解，解可以重算，题不能重建。
